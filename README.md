# 3秒ダイアリー（仮）

日常の動画を何本か選ぶと、それぞれ好きな3秒ずつ切り出して1本の動画につなげるアプリ。
参考: iPhoneアプリ「Film Log」。

## いまの段階（試作 v0.3）

ブラウザだけで動く Web アプリ（PWA）。Android の Chrome（メイン端末: Galaxy S24 Ultra）、iPhone の Safari、PC の Chrome で動く。
動画はサーバーに送らず、すべて端末の中で処理する。

できること
- 動画を複数まとめて選ぶ、≡ をつかんでドラッグで並べ替え、日付順に並べる
- 1本ずつ編集する画面（タブ切り替え）
  - 範囲: フィルムストリップ上のオレンジ枠をドラッグ、0.1秒/0.5秒の微調整、日付の修正
  - 色味: 8種（なし/フィルム/夕暮れ/ふんわり/あざやか/クール/モノクロ/セピア）、フィルムの粒子、ふちを暗く、日付スタンプ（全クリップ共通）
  - 文字: 18書体（Google Fonts）、8色、大きさ、そのまま/影/ふち/帯、画面上でドラッグして位置を決める、「この書式を全部に」
  - プレビューは書き出しと同じ見た目
- 仕上がり: 1本の長さ 1/2/3/5秒、縦・横・正方形、いっぱいに/全体を入れる、切り替え（パッと/ふわっと/ピカッと）、画質 720p/1080p、音声あり/なし
- 設定・文字の書式は端末に保存される
- mp4 で書き出し → 保存・共有（https のときのみ）/ダウンロード
- ホーム画面に追加できる（manifest + Service Worker。https で公開したときに有効）

## 動かし方（PC で確認するとき）

```bash
python -m http.server 8000
```

- PC: http://localhost:8000
- スマホ（同じ Wi-Fi）: http://<PCのIPアドレス>:8000

## 仕組みと既知の制約

- 書き出しは `<canvas>` に映像を描き、`MediaRecorder` で録画する方式。
  そのため **完成動画の長さと同じだけ時間がかかる**（＋各クリップの助走0.5秒）。書き出し中に画面を閉じると失敗する。
- 各クリップは開始位置の0.5秒手前から再生し、映像が流れ出してから録画を再開する（冒頭のカクつき対策）。
  開始位置が0秒のクリップは、最初の約0.1秒が使われない。
- 描画は最大30コマ/秒。文字と日付は1枚の画像にまとめておき、毎コマ重ねるだけにしている（軽量化）。
- 写真ライブラリから選んだ動画は、撮影日ではなく選んだ日時が入ることがある → 日付は手動で直せる。
  Galaxy のファイル名（例: 20261013_153012.mp4）からは撮影日を自動で読み取る。

## 配布の方針（2026-10-14 時点）

- 第一目標: Google Play。できれば App Store にも出す。
- 想定: この Web アプリを Capacitor でアプリ化（Android は Windows だけでビルド可能）。
  iOS のビルドには Mac かクラウドの Mac ビルドサービスが必要。Apple Developer Program は年 $99。
- それまでは https で公開して、スマホだけで使えるようにする。
